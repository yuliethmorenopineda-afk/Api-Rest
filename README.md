# Mundial (Spring Boot + MongoDB Atlas + Thymeleaf + Bootstrap 5)

Importar en STS: File > Import > Maven > Existing Maven Projects > carpeta `Mundial`.
Ejecutar `MundialApplication` (Run As > Spring Boot App) -> http://localhost:8080

Paquetes: com.mundial.app, com.mundial.app.Controlador, com.mundial.app.Entidades, com.mundial.app.Repositorio
Orden de registro: Estadio / Asociacion / Entrenador -> Club -> Jugador / Competicion
